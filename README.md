# Sim1.0

Possession-by-possession NBA simulator — Go backend, React frontend.

## Quick start

**Backend** (API on `:8080`):
```bash
cd backend
go run ./cmd/server
```

**Frontend** (dev server on `:5173`, proxies API to `:8080`):
```bash
cd frontend
npm install
npm run dev
```

See [backend/README.md](backend/README.md) for API reference and config details.
